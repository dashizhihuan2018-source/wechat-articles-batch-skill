# 热门公众号文章项目调研（2026-10-27，Asia/Shanghai）

## 方法、范围与限制

目标是“与公众号文章批量采集直接相关的高星项目”，不是所有微信开发项目的总榜。用 Google 与通用网页检索发现候选，再用 GitHub REST API 搜索仓库并逐项回读星数、许可证、归档标志、README和关键文档；排除微信SDK、聊天机器人、通用教程集及无关关键词命中。星数只是累计关注，不是实际成功率或近期热度。以下为本次检索候选集，不声称全网穷尽或稳定的 Google 排名。

Google 已通过原生 Chrome 成功检索并读取搜索结果页（自动转至google.com.hk），两组查询：

- `github wechat article exporter wewe rss`：可见exporter原仓库、其fork、WeWe RSS原仓库、Star History及工具对比页面。
- `github 微信公众号 批量下载 文章`：可见qiye45/wechatDownload、wechat-article组织、yangbuyiya/EasyWechatDownload及相关教程。EasyWechatDownload为补充低星线索（GitHub API快照87星、MIT、2026-07-14 pushed_at），未深入测试，不作为高星默认。

这些是当时实际可见的候选，不以结果位置判定全网热度；搜索摘要可能滞后（例如旧教程的星数与功能），最终判断回到仓库当前资料。早期命令行直连25秒超时、网页工具不可达、内置浏览器控制超时；它们属于通道问题，不代表Google最终没有检索成功。未绕过验证码、登录Google、修改代理或改变系统设置。公开记录只保留上述查询和候选，不含浏览器账号、位置推断、跟踪参数或原始界面快照。

GitHub API 查询（`sort=stars&order=desc`，UTF-8查询经编码）：

- `微信公众号 下载`（177个命中，检查前15个）
- `微信公众号 爬虫`（260个命中，检查前18个）
- `微信公众号 RSS`（79个命中，检查前10个）

宽泛查询可能命中描述很长的无关仓库；不能直接把搜索前几位当专业工具排名。`jooooock/wechat-article-exporter` 当前转至 `wechat-article/wechat-article-exporter`；按现仓库身份去重。

## 影响技术选型的关键证据

1. **最高星项目不再等于可行默认。** [exporter停维公告 #200](https://github.com/wechat-article/wechat-article-exporter/issues/200) 与[当前 README](https://github.com/wechat-article/wechat-article-exporter/blob/master/README.md)说明上游核心接口关闭，原一键同步路线失效；README记载在线域名计划2026-10-30到期。这是作者计划，不是本次对未来域名状态的验证。API的 archived=false 与作者停维声明不是同一概念。
2. **维护中也不能泛化模式能力。** [WeRSS微信读书模式文档](https://github.com/rachelos/we-mp-rss/blob/main/docs/weread-mp.md)说明旧列表接口已废弃，新 cover 只返回最新一篇，不支持历史回补；正文失败可空内容入库，后续去重会跳过。故“已入库”不等于“全文成功”，必须单列 missing_body；多次推送/多图文的完整覆盖仍需实际验证。
3. **自托管可能仍有外部中转。** [WeWe RSS README风险声明](https://github.com/cooderl/wewe-rss/blob/main/README.md)披露部分请求通过第三方转发。作者承诺不存储不是独立安全审计；不得将用户Cookie悄悄送给中转，且项目已归档。
4. **桌面工具与开源代码区分。** [wechatDownload根目录](https://github.com/qiye45/wechatDownload)主要是发布说明、示例和技能；说明要求在微信浏览器打开链接取得密钥。仓库公开不等于程序源码开放或许可证完整；不复制其未获许可实现。它自带Skill/MCP也不能替代下载程序的信任审查。README的“学习/24小时删除”文案不等于法律豁免，本技能不提供法律结论。
5. **原始正文与渲染缓存的容量分别预算。** [WeRSS issue #432](https://github.com/rachelos/we-mp-rss/issues/432)报告原HTML、清洗正文与缓存重复放大的问题。它是用户报告，不推断当前所有版本均未修复；部署选定版本后再查修复状态与配额。

## 官方渠道与不确定项

官方公众号已发布内容接口的[文档入口](https://developers.weixin.qq.com/doc/offiaccount/Publish/BatchGet.html)本次无法直接打开，**未核实最新账号资格、额度或参数**。需要时登录本人后台核验权限，再查当前官方文档；它不是任意公众号搜索API。不要将公众号后台页面的私有接口与官方服务端 API 混为一谈。

本技能不保证任意公众号全量历史、被删除/隐藏文章恢复、阅读量评论等互动指标、无限并发或零封号。下一次实务采集仍须输入账号/文章范围、授权和小样本测试。本次离线整理测试不补足这些在线证据。
